## 正式纳入标准

每一篇中文文献必须同时满足：

1. 能确认论文题名、完整作者、年份、期刊/会议、卷期页码或 DOI。
2. 能读取官方摘要或全文，不能只依赖搜索引擎摘要和二手解读。
3. 能明确指出它支撑研究现状中的哪一句话。
4. 不把综述中的二手描述用来替代某个系统原始论文的具体机制和实验结论。
5. 不把中文作者发表的英文论文计作“中文文献”。
